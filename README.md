# 🛍 Diwali Sales Data Analysis (Python Project)

This project focuses on analyzing customer purchasing behavior during the Diwali festival using Python. The insights from this analysis can help businesses improve marketing strategies and target the right audience.

##  Objective

To perform exploratory data analysis (EDA) on real-world Diwali sales data to:
- Understand customer demographics
- Analyze purchase trends
- Identify top-performing states and products
- Help businesses make data-driven decisions

##  Tools & Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📁 Dataset

The dataset used is a Diwali sales CSV file containing customer demographics, product categories, purchase amounts, etc.

##  Key Steps Performed

1. **Data Cleaning**
   - Removed unnecessary columns
   - Handled missing values
   - Corrected data types

2. **Exploratory Data Analysis (EDA)**
   - Gender-based purchasing trends
   - Age group distribution
   - Marital status and its effect on buying
   - State-wise sales analysis
   - Product category popularity
   - Top-selling products

3. **Insights Generated**
   - Males aged 26–35 are the top buyers
   - Married individuals spent more
   - Uttar Pradesh, Maharashtra, and Karnataka showed highest sales
   - Food, Clothing, and Home décor were the most popular categories

## 📷 Visualizations

Bar plots, count plots, and horizontal charts were used for clear and insightful visualizations of the trends and findings.

## 📝 Conclusion

This analysis helps identify the customer segments and products contributing most to Diwali sales. It can be used to guide marketing efforts and stock planning for future festive seasons.
